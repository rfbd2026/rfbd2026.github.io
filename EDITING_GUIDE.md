# Editing Guide — Projects and Shop Products

This is the written handoff in place of a recorded Loom. It doubles as a short walkthrough script for a future recording; it does **not** claim that a Loom video was made.

## Three-minute walkthrough outline

- **0:00–0:30 — Open the project:** The live Manus Preview is bilingual. `/en` is English/LTR and `/fa` is Persian/RTL. Portfolio data lives in `content/work/`; shop catalog data lives in `lib/products.ts`.
- **0:30–1:40 — Add a project:** Make a lowercase, hyphenated folder under `content/work/`, add a `project.md` using the schema below, and place a genuine cover image at `images/cover.webp`. The prebuild/predev sync copies supported raster formats to `public/projects/` automatically. The case-study route is generated from the folder slug.
- **1:40–2:30 — Update a product:** Edit the matching product object in `lib/products.ts`, preserving exact USD and Toman integers, bilingual copy, included items, license, and truthful preview alt text. Product detail pages and sitemap paths come from this list. Product illustration is mapped by style in `components/product-preview.tsx`.
- **2:30–3:00 — Verify safely:** Run lint, typecheck, and build. Adding a catalog entry never creates native files, grants a download, or opens checkout. The server-side purchase gate remains closed until final native bundles are supplied and verified.

## Add a portfolio project

1. Add a folder such as `content/work/new-project-slug/`.
2. Add genuine source artwork in `content/work/new-project-slug/images/cover.webp`. The asset-sync script copies supported image files to `public/projects/`; for the `cover` field, the content schema accepts WebP, PNG, or JPEG. Preserve the full portfolio page; do not crop away source context without approval.
3. Create `project.md` with YAML frontmatter like this:

```yaml
---
slug: new-project-slug
rank: 11
featured: false
category: Packaging
tags: [Social, Digital]
cover: images/cover.webp
source: Supplied project ZIP, exact source page

title:
  en: Verified English project title
  fa: عنوان فارسیِ تأییدشده
summary:
  en: Describe only what the source visibly supports.
  fa: فقط آنچه در منبع دیده می‌شود توصیف کنید.
context:
  en: State brief/context only if it appears in the source.
  fa: زمینه را فقط اگر در منبع آمده است ذکر کنید.
shown:
  en: Name the visible formats and details.
  fa: قالب‌ها و جزئیات قابل مشاهده را نام ببرید.
categoryLabel:
  en: Packaging
  fa: بسته‌بندی
---
```

4. Use an existing supported category. Set `featured: true` only when selecting one of the six homepage projects. Never invent a client brief, result metric, date, process sketch, project-specific tool list, testimonial, or client logo. Do not add private contact details.
5. Run `pnpm run lint`, `pnpm run typecheck`, and `pnpm run build`. The `/work/:slug` route is generated by the content loader. The static route manifest already declares this dynamic pattern and should remain in sync if the route structure itself changes.

## Update one of the four shop products

- Edit the matching object in `lib/products.ts`; keep `priceUsd` and `priceToman` as explicit integer source values (never calculate a floating FX conversion).
- Update both English and Persian `title`, `summary`, `included`, and `license`; keep `previewAlt` explicit that the image is illustrative and native product files are not supplied.
- Product artwork is mapped by the four allowed `style` values (`packaging`, `deck`, `amazon`, `palette`) in `components/product-preview.tsx`. If you add a new style later, update both the `Product` style union in `lib/products.ts` and the corresponding generated-image mapping; do not reuse an unrelated preview.
- Adding a product entry does **not** add final files or enable purchase. A new purchasable slug would also need trusted server-side price/order handling, verified payment events, storage entitlements, and an approved asset gate. Do not remove `nativeFilesVerified = false` or weaken `lib/payments/gates.ts` as a shortcut.
- The `$199` mentoring offer is out of scope. Portfolio Review is `$79` / `3,500,000` Toman, and payment remains paused.

## Current safety boundaries

- Checkout endpoints remain closed. The live/Preview shop is informational and uses illustrative previews only.
- Internal test-sample markers are served only when explicitly enabled in local development; the route returns 404 in production/Preview. They are not customer files.
- Magic-link sign-in and all customer email delivery remain disabled until Aref explicitly authorizes Resend.
- Live Vercel commerce is not wired; a Vercel-reachable database has not been selected/provisioned. Do not claim a production sale or verified customer download.
